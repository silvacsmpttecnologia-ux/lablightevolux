# Arquitectura Release 1.0

Usuario -> Interfaz web -> Motor de simulación -> Persistencia local -> Visualización -> Conclusión

- Interfaz: HTML5 + CSS3.
- Lógica: JavaScript.
- Motor: E = I/d² con conversión cm->m y variación sinusoidal determinista.
- Persistencia: localStorage.
- Visualización: tabla + SVG.
- Despliegue: Netlify.

La arquitectura con smartphone, ESP32 y sensores pertenece a etapas de diseño anteriores y no a la Release 1.0.
