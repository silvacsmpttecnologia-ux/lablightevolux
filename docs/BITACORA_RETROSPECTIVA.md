# Bitácora retrospectiva consolidada

- Semana 3 (26/08/2026): definición de usuario, necesidad, pregunta inicial, roles y arquitectura con sensores/hardware.
- Semana 5: plan de MVP con smartphone + HC-SR04 + ESP32 + LED; validación física planificada, no ejecutada.
- Hito posterior: primera web con dos dispositivos y exceso de texto.
- Iteración: prueba con cinco participantes externos; se detectó dificultad de comprensión por cantidad de texto y orden.
- Rediseño: nueva web simplificada y explicación visual breve.
- Resultado posterior: 5/5 participantes comprendieron y completaron la experiencia.
- Release 1.0: web autónoma con motor de simulación, mínimo cinco distancias, tabla, gráfico, modelo y conclusión.
- Validación final: comparación matemática y repetibilidad computacional.

Los hitos sin fecha documental exacta se presentan como reconstrucción retrospectiva y no como registros semanales contemporáneos.
